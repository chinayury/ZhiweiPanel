  • 主域名：{{.Domain}}
  • 站点 ID：{{.SiteID}}

下一步该做什么

  1. 登录智维面板 → 站点 → {{.Name}} → 「文件」标签页，可在线浏览与编辑站点根目录
  2. 上传你自己的网站文件到根目录，覆盖本 index.html 即可
  3. 删除本文件后再次访问，会看到 nginx 的 403 Forbidden —— 证明没有 index 文件时站点不再"白嫖"欢迎页
关于防跨站隔离：直接用 IP（http://{{.IP}}/）访问本域名会看到 "Empty reply from server"（连接被 nginx 立即关闭）—— 这是 catch-all default_server 的预期行为，仅域名访问才能拿到真实内容。
